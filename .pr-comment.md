- [x] Lookup fields open the selected record in a new tab and offer Add {singular} at the bottom of the combobox (closes #82)

Job and Candidate on an application (and any other reference field) show an open-in-new-tab icon **immediately after the selected label**, not at the input's trailing edge. The icon is a real `<a>` sibling of the combobox trigger so the click does not nest inside the button or open the search dropdown. The Job link on application 20 is `/applicant-tracking/jobs/8`.

The combobox also takes optional `addUrl` and `addLabel`. When both are set, an Add action appears at the bottom of the list. InputReference fills those from the referenced entity's singular label **only when the current user may edit that entity** — the same `edit_permission` gate EntityView uses for "Add {label}" (there is no separate create permission). Example: `/applicant-tracking/jobs/create` labeled "Add Job". Lookups with no navigable entity, or whose `edit_permission` the user does not hold, omit both.
