## What changed

- **Keys.** Three call forms in `t()`: a message is its own key; `{ id, message }` prefixes it (`columnVisibility.View` replaces the deleted `context`); `{ id, defaultMessage }` is keyed by the id alone with the English as fallback. Metadata ids are typed tuples under the reserved `module.` root (`module.nwind.orders.field.city.title`), joined and escaped inside `messageId()`. The slug comes from `get_schema`'s `module_slug`, now on `SemSchemaTable`.
- **Render path.** `localizeMetadata` renders every entity, field, enum and child-relation label through `translate()`; sidebar, command palette, breadcrumb, module tiles and `View`'s parent label spell their keys inline in `t()`. The label scopes, `labels.ts`, `labelInventory`, `localeFile.mjs`, `LabelsTab` and `scopeLabels` are gone.
- **Files.** `public/locales/<code>.json`, flat `messages` plus `obsolete`; `en-US.json` is the index (`id -> source`) and is never loaded as a catalog. `src/locales` is gone; `glossary.json` and the translation guide moved to `scripts/i18n/`.
- **Discovery.** `src/i18n/missing.ts` records every rendered key with its source through the translate target — index first, then an empty entry in the language — only when the index lacks the key or its source changed. The browser test suite runs with the collector on against the dev server, so `pnpm check` fills the index. The drift gate in `i18nCatalogs.test.ts` is deleted; `i18n:extract` is an optional scan that prunes code keys, never `module.*`.
- **Endpoint and modes.** `GET/POST {base}/translations` with `{ locale, key, translation }`; `VITE_TRANSLATE_MODE` (`dev` / `stage` / `prod` / `off`, default `off`, registered at all seven points) plus `VITE_TRANSLATE_API_URL`, pushed in by `initConfig()` via `setTranslateTarget`. `apps/web/.env.development` sets `dev` for `vite dev`. `baseUrl` is gone from `useTable` and `useCreateRecord`; the dev writer answers the new contract from `public/locales/`.
- **Errors.** `src/i18n/errors.ts` parses the PostgREST body: hint normalization, the four-step key resolution, `${…}` → ICU in one pass with per-brace quoting, missing/null values filled with their own name, `details` as text. `src/lib/appError.ts` packages the app's own errors as template plus values; the twelve throw sites use it and `renderError` in `lib/apiErrors.ts` is the one renderer behind the six display sites.
- **Translate mode.** One list, one tab; the editor shows the key; `en-US` editing is offered only where a `prod` record exists.
